# Smart Meter Replacement

## Before you start
Confirm the meter number on the work order matches the meter on the wall. Photograph the old meter's reading before removal.

## Meter base adapter
Older 4-jaw meter bases need the adapter part PX-4417-B before a new smart meter will seat correctly. Inspect the jaws for heat damage; replace the whole base if jaws are discolored.

## After installation
Confirm the new meter powers up and joins the network within 15 minutes. If it doesn't show as online, power-cycle it once, then log a communications ticket.
