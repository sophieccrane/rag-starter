# Protective Relay Setting Changes

## Approval required
Any change to protective relay settings needs written approval from a protection engineer and a peer review before it is applied. Emergency changes need verbal approval, documented within 24 hours.

## Applying new settings
Save the existing settings file first. Apply changes during a planned window, then run a trip test to confirm the relay operates as expected.

## Record keeping
Upload the final settings file and approval record to the protection database within 2 business days.
