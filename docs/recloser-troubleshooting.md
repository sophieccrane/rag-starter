# Recloser Troubleshooting

## Recloser will not reset
First check the control battery voltage; it should read at least 24 V DC. If the battery is fine and the recloser still locks out, check the event log for a ground fault. Do not reset more than twice without finding the cause.

## Replacing the control board
If the control panel shows error E-17 or is completely dark with a good battery, replace the control board with part PX-4471-C. Download the settings file before removing the old board and load it onto the new one.

## Nuisance tripping
Frequent trips in dry weather often point to vegetation contact or a failing lightning arrester. Patrol the line downstream before changing any settings.
